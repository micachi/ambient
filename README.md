# Ambient — ずっと眺めていられる、ブラウザのスクリーンセーバー

時計として、そのまま眺めるものとして。インストール不要、ブラウザだけで動く
スクリーンセーバーです。置いておくと自動でシーンが移り変わります。

**https://ambient.wicachi.com/** ・ 便利ツール集: **https://tools.wicachi.com/**

## シーン

| | シーン | 内容 |
|---|---|---|
| 01 | 残像秒針 | 長秒針の軌跡を、長い露光のように残像で眺める |
| 02 | 言葉の時計 | 時刻を文章で表示。5 分刻みに光る語が変わっていく |
| 03 | 粒子時計 | 分が変わるたび、粒子が流れて時刻の数字を組み直す |
| 04 | 流れ場 | ゆっくり形を変えるノイズの場を、粒子が流れ続ける |
| 05 | 波干渉 | 複数の波源から届くうねりが、ゆっくり干渉し合う |
| 06 | 星屑 | ゆっくり流れる星屑。ときどき流星が筋を引く |

時計系が 3 つ、眺めるだけのが 3 つ。

## 操作

| キー | 動作 |
|---|---|
| `←` `→` | シーン切替 |
| `F` | 全画面 |
| `S` | 設定パネル |
| `H` | UI を隠す |
| `C` | 自動切替の ON / OFF |
| `+` `−` | 明るさ |

URL ハッシュでシーンを直接開けます（`#flow`、`#word` など）。
操作がなければ 4 秒で UI は消えます。

## 長時間表示への作り込み

スクリーンセーバーは「つけっぱなし」が前提なので、見た目の前に効いてくる話がある。

- **焼き付き防止** — 数分周期のリサージュで画面全体を少しずつ揺らし、
  同じ画素に同じ光が当たり続ける状態を作らない（`driftAt`）
- **省電力** — 既定 FPS 30 キャップ。落ち込み時にコマを追いかけないので
  発熱がフィードバックループにならない
- **まぶしさ抑制** — 明るさ 25% まで絞れる。明滅は使わず、必ずフェード
- **非表示時に停止** — `visibilitychange` で描画を止める
- **reduced-motion 配慮** — OS でモーション低減なら動きと FPS を自動で落とす
- **DPR 1.5 上限** — Retina をそのまま拾うとピクセル数が倍になり熱になる

## 仕組み

依存ゼロの Canvas 2D。ビルドは `build.mjs` で ja / en の 2 ページを出すだけ。

```
assets/scenes.js   6 シーン（それぞれ独立した状態を持つ）
assets/app.js      描画ループ・シーン管理・UI・設定永続化
assets/style.css   オーバーレイ UI
build.mjs          dist/ 生成
test.js            73 件のテスト
```

```bash
node build.mjs
npm install && npm test   # テストには jsdom と canvas が必要
```

テストは実際に node-canvas で描画して画素を検査している
（「例外なし」だけでなく「画面に何か描かれている」まで見る）。
ワードクロックは全 1440 分ぶん、返すトークンが盤面に存在するかを検証。

## プライバシー

すべてブラウザ内で完結します。入力も個人データも送信されません。
サーバーは静的ファイルを配るだけです。
